# 워드득

**영어와 일본어 회화 표현을 하루 30개씩 익히는 단어 학습 서비스**입니다. 카드를 보며 단어를 외우고, 양방향 퀴즈로 기억한 내용을 확인할 수 있습니다.

**[워드득에서 공부하기](https://worddeuk.kr/)**

## 이렇게 공부해요

1. 영어 또는 일본어를 고르고 학습할 Day를 선택합니다.
2. 단어 카드에서 표현과 예문을 확인하고, 가려진 뜻이나 표현을 눌러 공개합니다.
3. 외운 단어에 체크하면 체크 애니메이션이 끝난 뒤 다음 카드로 넘어갑니다. **외운 단어 제외**가 기본값이며, 필터를 끄면 외운 단어도 다시 볼 수 있습니다.
4. 한국어→학습 언어와 학습 언어→한국어 퀴즈를 풀고, 오답노트에서 최근에 틀린 표현을 복습합니다.

카드 섞기, 단어 리스트, 오답만 보기, 발음 듣기와 모바일 스와이프도 지원합니다. Day별 학습 완료 상태, 단어별 암기 상태, 퀴즈 최고 점수를 저장합니다.

## 이용 범위와 학습 기록

| 이용 방식 | 학습 범위 | 기록 보관 |
| --- | --- | --- |
| 비회원 | 영어·일본어 Day 1~3 | 사용 중인 브라우저 |
| Google 로그인 회원 | 영어·일본어 Day 1~50 | 브라우저에 저장하고 계정과 자동 동기화 |

비회원으로 공부하다가 **같은 주소(`worddeuk.kr`)에서 로그인**하면 브라우저의 학습 기록을 계정 기록과 병합합니다. 로그인 회원의 이후 변경 사항도 자동으로 동기화합니다. 비회원 기록은 사용 중인 브라우저에만 저장되므로 브라우저 데이터를 삭제하면 복구할 수 없습니다.

Day 51~100 콘텐츠는 아직 제공하지 않습니다. 소개 화면의 **내 텍스트로 공부하기** 버튼도 현재 이용할 수 없습니다.

## 프로젝트 정보

워드득은 React·Vite 프론트엔드와 Spring Boot 백엔드로 구성된 오픈소스 프로젝트입니다. 공식 서비스는 AWS EC2에서 제공하며, 회원 학습 기록은 Neon PostgreSQL과 동기화합니다. 시스템 구성과 데이터 처리 방식은 [시스템 구조 안내](./SYSTEM_ARCHITECTURE.md)를 참고해 주세요.
